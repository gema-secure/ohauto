## 二、启动（固定命令，原样粘贴）

```bash
cd D:\project\ohauto-system
"C:/Users/gema2/.workbuddy/binaries/python/versions/3.13.12/python.exe" -u examples/run_suite.py examples/cases/calculator.yaml --repeat 220 --out tools/_out/b11_stability_2h --artifact-budget 60 --quiet > tools/_out/b11.log 2>&1
```

要点（每条都有教训背书）：
- `-u`：无缓冲——进程被杀也留得住已产生的日志；
- `--out`：**每轮增量落盘** `suite_report_partial.json`（本轮起生效）——被杀只能丢掉「正在跑的那一轮」，已完成轮次全在；
- `--artifact-budget 60`：产物轮转，2 小时不会撑爆磁盘；
- 靶子用 `calculator.yaml` 是**故意的**：隔离变量，失败可归因于框架而非应用；大应用的资源类长稳是另一件事（B15，另列）。

## 五、已知坑（全部本周实测）

| 坑 | 现象 | 处置 |
|---|---|---|
| 日志全缓冲 | 后台跑时 `tail` 看不到进度 | 已用 `-u` 解决；查进度看 partial json |
| 外部终止 | 终端被关 = 进程死，日志被缓冲的部分全丢 | 增量落盘已根治；**跑的时候别关终端**仍是铁律 |
| 中途息屏 | 息屏 → 锁屏不进无障碍树 → 树全空 | 引擎每轮自动重钉息屏超时，已根治 |
| 分离进程启动 | 每次(hdc 调用)闪一个终端窗口 | **禁止**——长稳只走本指南的后台方式 |
| 双峰振荡误报 | 逐轮中位 4650/5030 交替 ~8% | 阈值 15% + 半程对比法，工具已按此校准 |
