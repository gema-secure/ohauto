### 5.1 关于 50 步成功率：我采纳你的补丁，但 `kpi_ok` 的语义要再掰一次

你的补丁我照抄，**只有 `kpi_ok` 这一条要改**：

```python
    def kpi_ok(self, target: float = 0.95) -> bool:
        return (not self.all_failed) and self.non_cascade_failure_rate >= target
```

问题：**`not all_failed` 这道闸只能挡住「100% 失败」，挡不住「90% 失败」。**
50 步里挂 45 步、其中 44 步判 cascade → `non_cascade_failure_rate = 0.98`、
`all_failed = False` → **`kpi_ok()` 照样返回 True**。评审算的那个反例其实
只需要「大部分同类失败」，不必「全部失败」。

所以我要加一条**独立的**健康度判据，跟那个率并列：

```python
    @property
    def health_ok(self) -> bool:
        """用例整体健康 —— 与 non_cascade_failure_rate **并列**、不互相替代。"""
        return self.failed == 0
```

报告里**两个都打**，谁也不许单独当通过依据。这样「0.98 的非级联率 +
45/50 失败」在报告上是**并排两个数**，读的人不会只看一个。

> 这跟我 9-22 复核评审时那条结论是同一个立场：
> **一个数只回答一个问题。** 那个率回答「引擎健不健壮」，

### 11.2 红灯 2（`from_case_result` 不继承快照）—— **我在集成层修了，但你那边也要收口**

我修在集成仓库的 `diagnose.py`（因为它是阻塞项，不修闭环接不上）。修法与
§2.2 里说的一样，**关键是多做了一层**（这是你没意识到的那层）：

```python
def _load_step_trees(step):
    """把 StepResult.trees 里的**快照路径**读成控件树文本。"""
    for t in getattr(step, 'trees', None) or []:
        if isinstance(t, LayoutNode):
            out.append(t); continue
        if not isinstance(t, str): continue
        if t.lstrip()[:1] in ('{', '['):     # 已是控件树 JSON 文本
            out.append(t); continue
        try:
            with open(t, encoding='utf-8', errors='replace') as f:
                text = f.read()
        except OSError:
            continue                          # 读不到就跳过，不制造 None 占位
        if text.strip():
            out.append(text)
```

**为什么必须多做这一层**：`StepResult.trees` 存的是**文件路径**，
而 `_parse_trees()` 只会 `parse_layout(t)` —— **接不了路径**。
若直接把路径列表赋给 `rec.trees`，会从「恒空」变成「**恒 None**」

⚠️ 这两者**看起来都是「没有快照」**，但性质完全不同：
- 空列表 = 诚实的「没有证据」
- `[None, None]` = **假装有证据但解析失败了**，会污染 `_parse_trees` 的返回值，
  让下游「快照数量」这类判断全部失准

**这条你要在你自己那份包里同步修** —— 否则两边分叉，我这边修了、你那边还是旧的。
