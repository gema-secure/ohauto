## 六、答辩时最可能被追问的三句，怎么答

**Q：「94.7% 是准确率吗？」**
→ 不是。它是「视觉通道给出的框与控件树给出的框是否一致」（IoU/中心命中），
标注源自控件树文案，衡量的是**双通道一致性**。这个口径写在验证报告第一节。

**Q：「用例生成的可执行率多少？」**
→ **还没有真实数字**。目前跑通的是 ScriptedProvider 的链路验证（证明管线与
校验/修复逻辑正确）；真实 LLM 的评测尚未做，需要配置 key 后按同一套口径跑。

**Q：「你们在几台设备上验证过？」**
→ 物理真机 **1 台**（DAYU200），另有 4 个**模拟器实例**用于跨形态。
命题没有多设备要求；架构是宿主侧 + 语义匹配，不绑定具体机型。
