# P3 对标 —— 往届参赛作品怎么写（风格研究 · 2026-09-28）

> **目的**：P3 材料（作品简介 / 项目文档 / 视频）动笔前，先看往届真实参赛材料长什么样。
> 结论：往届写得好的作品都**不用华丽修辞**，全靠「一句话定位 + 数字 + 结构清晰的工程叙述」。

## 二、往届的结构（惊人地一致）

以蓝目AI 帖子为完整样本，结构是：

```
一句话定位（这是个什么东西，给谁用）
→ 解决方案（4~5 条，每条一个加号短句，一条一个卖点）
→ 项目架构（分 4 层，每层一句话）
→ 技术特性（与架构呼应）
→ 市场前景 / 应用领域（1~2 句收尾）
```

华为官网获奖简介则是更短的一句话句式：

> "本应用是一款 XX 类应用，通过使用 HarmonyOS 的分布式能力，实现了……，
> 为用户提供了……体验。"

工程文档类（复旦样本）最朴素：简介（背景/目的）→ 设计描述 → 模块划分 → 文件结构。
原句风格："本文档的主要目的是对本项目的设计和实现进行说明"。

## 三、语言风格规律（可以直接抄的）

1. **短句直陈，动词驱动**。"实现了高度仿真""打通家居设备间互联壁垒"——主语+动词+宾语，少用长从句。
2. **每条卖点只讲一件事**，一条一行的加号/短横列表，不写大段。
3. **数字放中间不放结尾**。蓝目AI 直接写 "RAG + 向量数据库"、"GPT4 等先进大语言模型"这种具体名词。
4. **拔高句只出现在开头结尾各一句**（"顺应时代机遇""为万物互联贡献力量"），正文全是干货。
5. **第一人称"我们"少量出现**（仓颉样本："我们团队以国产化技术为核心，打造了……"），不回避但不滥用。
6. **团队分工实名列出**（仓颉样本 01 节：每人一行，负责什么）。
7. **用运行结果自证**：Road Rage 直接放效果预览；温度计队伍把功能证明视频放网盘贴链接。

## 四、反面清单 —— 什么是一眼 AI 腔（我们材料里禁止出现）

| 禁止 | 理由 | 改成 |
|---|---|---|
| "值得注意的是""总而言之""综上所述" | 往届样本零出现 | 直接说事 |
| "赋能""抓手""底层逻辑""范式"连用 | 往届只在"助力数字化转型"一处收尾用过"助力" | 说具体机制 |
| 排比堆叠（三个"不仅…更…"连发） | AI 高频，人很少这么写 | 一句一个论点 |
| 每段都以"通过 X 实现 Y"开头 | 模板痕迹太重 | 变换句式，或直接给数字 |
| 形容词堆叠（"强大的""极致的""全方位"连续出现） | 华为官方简介偶尔用一个，我们不用 | 用数字替代形容词 |
| emoji、花哨分隔符 | 往届工程材料零 emoji | 纯文本 |
| 过度分层（四级标题嵌套） | 往届最多三级 | 两级标题 + 列表 |
| "闭环"一词脱离具体技术含义乱用 | 我们只有「归因→自愈」一处是真闭环 | 只在自愈语境用 |

## 五、对我们材料的落地要求

1. **作品简介** ≤ 1200 字，结构照蓝目AI 样本：定位 → 痛点 → 方案 → 架构 → 实测数字 → 命题对应。
2. **所有数字只从《指标汇总-2026-09-24》取**，口径红线照搬（94.7% 是一致性不是准确率；
   注入式离线验收与真机数字两行并列不混用；模拟器 ≠ 真机）。
3. 修复前口径的数字（L3 步骤级 77.8% / 用例级 40%）**初稿先不上**，等 P1 翻新后再定。
4. 视频脚本另出，但风格要求相同：先给结论，再给证据画面（截图+控件树叠加）。

## 六、语体要求（09-28 C 意见纠偏，最高优先级）

**去 AI 语气 ≠ 口语化。** 材料语体必须是**规范书面语**（公文体/技术文档体），
问题陈述明确、措辞正式。两版对照示例：

| ❌ 大白话（初稿犯的错） | ✅ 规范书面语 |
|---|---|
| 纯控件树，测试从根上就站不住 | 单一控件树通道无法支撑稳定的控件定位 |
| 靠人看日志猜 | 问题定位依赖人工排查，结论不可复核 |
| 跑起来却是空壳 | 步骤全部通过，但缺少断言与实质动作 |
| 每一步都先问一句：这一步能不能失败 | 逐步校验该步骤是否具备失败可能 |
| 这就是我们为什么必须做视觉通道 | 多模态信息融合是必要条件 |

操作规则：
1. 禁止口语词：跑通（→执行通过/验证通过）、拉起（→启动/唤起）、卡点（→阻塞项）、
   空壳（→缺乏实质验证的用例）、翻新（→更新/重新评测）、漏网（→未覆盖项）；
2. 禁止设问句、感叹句、第二人称；
3. 问题用「问题一/二/三」编号陈述，每条 = 现象 + 数据 + 后果，一段说清；
4. 主语用「本作品/本系统/系统/团队」，全文不用「我们」超过 2 次；
5. 语气判断标准：读出来像正式提交的技术报告，不像人聊天，也不像 AI 演讲。
