## 六、已知的坑（**踩过的，别重复踩**）

### 6.1 环境 / 工具

- **装包带清华镜像**（默认源实测卡 12 分钟）；`cmd | tail -N` 会**全缓冲**，
  后台跑看不到进度 → 直接 `> log 2>&1`
- **不能从脚本调 PowerShell**（安全策略拦），且唯一入口无回显 →
  **依赖 PowerShell 的方案无法自动集成**
- **hdc 本地路径按 cwd 解析** → `os.chdir` 后再传纯文件名

### 6.2 ★ **「当前哪个模型可用」这类事实，搜索引擎给的很可能是过时快照**

今天实际踩到：搜到"只有 `deepseek-v4-flash-vision-exp` 吃图、每图 384 tokens"，
**其实是 9-10 之前的旧状态**。正确值是：

| | 正确 |
|---|---|
| DeepSeek 视觉模型 | **`deepseek-flash`**（= V4.1-Flash，原生多模态） |
| 已下线 | `deepseek-v4-flash-vision-exp`（2026-09-10 下线，旧名路由到 `deepseek-flash`） |
| 不吃图 | `deepseek-v4-pro` |
| 图片计费 | 最多 **1024** input tokens/图 |

**是用户纠正后复查才发现的。** 这类事实必须**多处交叉验证**。

### 6.3 ★ **派活前先核实代码**（今天两次）

- 旧索引写「`build_page_signature` 要纳入 `pagePath`」→ 核实发现**早就在用了**；
- 「收敛 `identity_hint`」→ 核实发现 `label` 属性**已经是那个角色**，不需要做。

**不核实就派 = 让队友做无用功**，而且会让对方觉得你不清楚项目现状。

### 6.4 真机

- **锁屏 → `dumpLayout` 返回空树**且**不报错** → 用 `DeviceGuard.ensure_awake()`
- **USB 弹窗会霸占顶层窗口**（`com.usb.right`）→ `aa force-stop com.usb.right`；
  若控件树看着像桌面，**先截图看一眼**
- 拉起应用必须 `force-stop` → `Home` → `start` 三步（`aa start` 会复用实例）
- **可点控件自身 id/text/descr 常全空**，文案在 `text_deep`

### 6.5 度量（**这类坑最贵**）

- **一条在所有正常样本上都命中的判据等于没有判据**（"越出父容器"7 样本命中 69 次 → 弃用）
- **别用会被上限截断的量去比大小**（今天写测试时踩到：两个置信度都被 cap 到 1.0）
- **「没配到样本」≠「健康」**；**「缺源」≠「没问题」**
- **口径不同的两个数不能直接相除**（页面覆盖率 267% 就是这么来的）
