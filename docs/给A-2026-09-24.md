## 一、🔴 请优先收口：自愈的幂等「代次」不推进（**当前唯一卡点**）

### 1.1 现象

跑这条命令（设备不需要在位，用 `FakeHdc`）：

```bash
python tools/wire_locator_sink.py
```

会看到：

```
第 1 次失败 → A 侧连续失败 : 0 -> 1        ← 正常
又失败 5 次后连续失败 : 1（期望接近 6）    ← 不对：后 5 次全丢了
```

**连续失败永远停在 1，自愈阈值达不到 → 自愈永远不会触发。**

### 1.2 根因（精确到行）

`ohauto/locator.py:542` `_count_failure()`：

```python
def _count_failure(self, locator_id: str, reason: str) -> bool:
    h = self._health.get(locator_id)
    if h is None:
        return False
    if self._fail_seq.get(locator_id) == self._locate_seq:      # ← 问题在这
        self._log(f'{locator_id} 同一次定位失败的重复记账，已去重: {reason}')
        return False
    self._fail_seq[locator_id] = self._locate_seq
    ...
```

幂等键是 **(locate 代次, locator_id)**，而 `_locate_seq` **只在 `locate()` 里推进**。

**但执行器走的是 `matcher`/`layout`，从来不调 `locate()`** ——
`runner.run_step()` 里是 `exec_action(driver, action, arg)`，
`driver.tap()` 内部走 `matcher.filter(flatten(tree))`，全程不碰 `LocatorManager`。

于是 `_locate_seq` 恒为 0：第一次失败后 `_fail_seq[lid] = 0`，
**之后每一次真实失败都满足 `_fail_seq[lid] == _locate_seq`，被判成「重复记账」丢弃。**

### 1.3 这个幂等是怎么来的（不是你的错，是前提没成立）

幂等的口径是 2026-09-23 定稿的（回执 2.2），当时的假设是：

> 「同一次定位尝试内，内部记账与执行器回写谁先到谁生效；**下一次 `locate()` 代次推进后
> 照常记账**」

这个假设依赖「执行器会调 `locate()`」。而现实是执行器**根本不经过 `LocatorManager`** ——
两边对同一个词的指代不同，就撞上了。

### 1.4 影响（为什么要优先）

1. **自愈永远不触发** —— 这是挑战 #5「崩溃/异常 → 归因 → 自愈」和挑战 #6
   「用例沉淀复用」的最后一环，也是我们相对业界方案（HapTest / HmTest）的**核心差异化**；
2. 归因结论里已经正确带上了 `locator_id`（我这边刚接通的，见 §3.1），
   却被这一步吃掉，**看起来像"归因没生效"，实则是记账被去重**；
3. 真机连续跑用例时，**同一个定位器反复失败却永远不换代**。

### 1.5 建议修法（两个方案，你选）

**方案 A（推荐）：让代次可由执行器显式推进**

```python
def begin_attempt(self) -> int:
    """执行器每发起一次「定位尝试」前调用，推进代次。

    执行器不经过 locate() 时，靠这个显式推进 —— 代次语义从
    「locate 调用次数」变成「定位尝试次数」，与它的去重意图一致。
    """
    self._locate_seq += 1
    return self._locate_seq
```

C 这边在 `Runner.run_step()` 的重试循环里调用（每个 attempt 一次），
**改动点只在 C 的文件里**，你只需提供这个方法。

**方案 B：幂等键换成「执行尝试序号」**

`record_locator_failure(locator_id, reason, attempt_id)` ——
同一个 `attempt_id` 内去重，不同 `attempt_id` 照常记账。
代价是**改签名**，B 侧调用点也要动（B 已承诺"定案失败只调一次"，影响可控）。

> 我倾向 **A**：不改签名、不动 B、语义更贴近意图。
> 如果你认为还有第三种更干净的改法，按你的来 —— 但请在回执里写明，
> 我会同步更新 `tools/wire_locator_sink.py` 的自测判定。
